# AuthorityIQ

AI Authority Intelligence & Action Platform.

AuthorityIQ measures, diagnoses, prioritizes, and improves how brands are discovered, cited, and recommended by generative AI systems.

## Operating loop

Observe → Diagnose → Prioritize → Act → Measure

## V1 foundation

- Multi-tenant Supabase/Postgres architecture
- Row-level security
- AI provider abstraction
- Prompt execution pipeline
- Response normalization and extraction
- Visibility, recommendation, citation, and authority scoring
- Opportunity engine
- Reporting contracts
